1. Fundamentos

A base técnica indispensável: sistemas operacionais, redes, automação e contêineres.

Containers

Contêiner é uma forma de isolar um ambiente para executar códigos, aplicações e assim por diante. Docker é a ferramenta mais popular para criação e execução de contêineres.

Trilha de Estudo:

  • Vídeo introdutório: [Mayk Brito] Como funciona o Docker? (explicação SIMPLES)
  • Treinamento: [LinuxTips] Docker Essentials

Laboratório Girus: acesse o seu ambiente Girus, vá em Laboratórios e filtre por Docker. Faça os seguintes treinamentos:

  • Introdução ao Docker
  • Gerenciamento de Containers Docker
  • Redes no Docker: Conceitos e Implementação
  • Persistência de Dados com Docker Volumes
  • Introdução ao Docker Compose

Pratique cada um desses laboratórios antes de seguir para o próximo tópico.

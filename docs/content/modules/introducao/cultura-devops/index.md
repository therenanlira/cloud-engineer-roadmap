# Cultura DevOps

A cultura DevOps une desenvolvimento de software (Dev) e operações (Ops), focando em automação, entrega contínua, testes rápidos e colaboração entre os times.

* <i class="fas fa-video"></i> **Vídeo introdutório:** [[Código Fonte TV] DevOps // Dicionário do Programador](https://youtu.be/iwf6kcvxeD4)
* <i class="fas fa-graduation-cap"></i> **Treinamento:** [[Microsoft Learn] Introdução ao DevOps](https://learn.microsoft.com/pt-br/training/modules/introduction-to-devops/)
* <i class="fas fa-graduation-cap"></i> **Treinamento:** [[LinuxTips] Agile Essentials](https://linuxtips.io/treinamento/agile-essentials/)

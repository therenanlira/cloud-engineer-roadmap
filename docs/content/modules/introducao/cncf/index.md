# CNCF (Cloud Native Computing Foundation)

A CNCF (Cloud Native Computing Foundation) é uma organização sem fins lucrativos com objetivo de impulsionar e padronizar o desenvolvimento e a adoção de tecnologias open-source (código aberto) voltadas para cloud computing (computação em nuvem).

* **Site oficial:** [Cloud Native Computing Foundation](https://www.cncf.io/)
* **Vídeo explicativo:** [O que é Cloud Native, o LinuxFoundation e a CNCF](https://youtu.be/z2q0gKL9nQg) (ative a legenda em Português)

Boa parte das ferramentas open-source que você vai usar neste roadmap (Kubernetes, Prometheus, ArgoCD) são projetos da CNCF.
